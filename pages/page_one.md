# Advantages of Open Source Software

## Transparency and problem solving

Open-source software is defined as software where the code is publicly available. This means that the software may be studied and changes may be proposed. Unlike closed source software this allows users greater freedom and control of the technology they use. It also makes the technology more transparent and the responsibility of identifying problems might be shared among more contributors.  

To elaborate on why transparency is an obvious advantage, one can add that open source makes it possible for any programmer, researcher, student, to examine how the program works. This makes it possible for the user to identify errors, propose changes and see how the data is handled. This makes the software more reliable and trustworthy at the same time as it may be improved more effectively. 

For researcher on specific topics this may also provide an opportunity to adapt the software for their specific needs. For example, if you’re researching nineteenth century Norwegian literature, and you have a program that works well in identifying and counting word frequencies, you might end up with a problem regarding how the language has changes from the nineteenth century until today. The modern program might not have this information, but with access to the source, you might do some handy programming work and help the program identify these changes. This would not be possible in closed-source, commercial software, where you get the software as is with no possibility to change it whatsoever. 

Lastly, the open-source programs do not depend on any single person, organization or company to keep running. This makes it possible for useful tools to keep on living past their originators have pasted on to other project or died. This makes for long term development of complex programs, which obviously benefits them.
