# Advantages of Open Source Software

## Transparency and problem solving

Open-source software is defined as software where the code is publicly available. Unlike closed source software this allows users greater freedom and control of the technology they use. It also makes the technology transparent, and more contributors means more eyes to identify problems. This makes the software more reliable and trustworthy at the same time as it may be improved more effectively. 

For researcher on specific topics this may also provide an opportunity to adapt the software for their specific needs. For example, if you’re researching nineteenth century Norwegian literature, and you have a program that works well in identifying and counting word frequencies, you might meet a problem regarding how the language has changes from then until today. The modern program might not have this information, but with access to the source, you might do some handy programming and help the program identify these changes. This would not be possible in closed source, where you get the software as is with no possibility to change. 

Lastly, the open-source programs do not depend on any single person, organization or company to keep running. This could expand the programs life, since others may take control after their originators have pasted on.
